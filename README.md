# Занятие 4 — раздатка

Сегодня настраиваем агента под себя и превращаем идею в живую страницу. Разбираемся, как агент
зовёт на помощь других агентов, собираем первый skill, ставим Superpowers, и он проводит с
тобой брейншторм по твоей идее. Из брейншторма вырастает лендинг: его по плану собирает
команда субагентов, и в конце занятия он уже живёт в интернете.

Дорога курса: **найти идею → обсудить её → дать себя допросить → записать → разбить на задачи
→ делать по одной.** Идея найдена на занятии 3. Сегодня второй шаг: **обсудить.**

## Сначала проверка

В VS Code открой папку `work` и попроси Claude Code:

```text
Покажи, что лежит в StartUp/yc-rfs и в claude-config.
```

Должны быть видны три файла с идеями (`product-ideas.md` среди них) и папка `claude-config` с
папками `skills` и `agents` внутри. Идею ты уже выбрал на занятии 3: открой `product-ideas.md`
и вспомни, какую. Чего-то нет, сразу пиши в чат курса.

## Промпты по порядку

| Шаг | Промпт | Что делает |
|---|---|---|
| 1 | [`agents-to-config.md`](prompts/agents-to-config.md) | Кладёт двух готовых субагентов в `claude-config/agents`: знатока документации и ревьюера |
| 2 | [`commit-skill.md`](prompts/commit-skill.md) | Первый skill в `claude-config/skills`: агент пишет коммиты по твоим правилам |
| 3 | [`superpowers-setup.md`](prompts/superpowers-setup.md) | Ставим плагин Superpowers. Руками, через `/plugin`, без терминала |
| 4 | [`landing-brainstorm.md`](prompts/landing-brainstorm.md) | Ядро занятия: брейншторм по твоей идее → дизайн → план → команда субагентов собирает лендинг |
| 5 | [`landing-deploy.md`](prompts/landing-deploy.md) | Лендинг уезжает на GitHub Pages, у тебя живая ссылка |

Промпты работают одинаково на Windows, macOS и Linux: агент сам определяет систему. На Windows
терминал только `cmd`, если открылся PowerShell, переключись.

К концу занятия у тебя в интернете две страницы: Persona и лендинг идеи.

## Готовые субагенты

Папка [`agents/`](agents/): два помощника, которых промпт 1 кладёт тебе в `claude-config`.

| Файл | Что делает |
|---|---|
| [`anthropic-docs.md`](agents/anthropic-docs.md) | Отвечает на вопросы про Claude Code строго по официальной документации и никогда не выдумывает |
| [`reviewer.md`](agents/reviewer.md) | Ревьюер без контекста проекта: код, текст, план, страница. Свежий взгляд со стороны |

## Домашнее задание

**К занятию 5, обязательно:**

1. **Лендинг живёт по ссылке.** Не успел на занятии, доделай промптами 4 и 5. Ссылку в чат
   курса.
2. 🧪 **MVP: брейншторм.** Задание [`mvp.md`](mvp.md), промпт
   [`mvp-brainstorm.md`](prompts/mvp-brainstorm.md). Агент помогает выбрать
   маленькую рабочую часть твоего продукта и записывает её дизайн. Строить пока не нужно: на
   занятии 5 этот дизайн разберём на задачи, и MVP пойдёт с тобой до конца курса.

**Для желающих:**

- 🎭 [Заведи агенту характер](character-skill-challenge.md): skill с личностью любимого персонажа.
  Файлом можно поделиться в чате.
- ⭐ Свой skill под задачу, которая повторяется у тебя в работе. Образец:
  [`commit-skill.md`](prompts/commit-skill.md).
- ⭐ Отдай лендинг субагенту `reviewer`: «посмотри страницу свежим взглядом, понятно ли за
  десять секунд, что это и для кого».

## Если что-то не получается

Пиши в чат курса. Скриншот того, что видишь на экране, помогает быстрее любого описания.
