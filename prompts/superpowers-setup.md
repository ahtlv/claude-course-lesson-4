# Ставим Superpowers

**Когда:** на занятии 4, перед перерывом. Если на занятии не получилось, сделай это до
следующего шага практики: без плагина брейншторм не поедет.
**Что делает:** ставит плагин Superpowers, набор готовых скиллов для Claude Code. Главный из
них нам нужен сегодня: **brainstorming**. Агент сначала расспрашивает тебя про задачу и
только потом что-то делает. То же самое, что мы на занятии 2 делали руками перед Plan Mode,
только теперь агент ведёт разговор сам.
**Как использовать:** это делается **руками**, мышкой, в окне Claude Code. Агент сам себе
плагин поставить не может.

Проект: [github.com/obra/superpowers](https://github.com/obra/superpowers)

## Шаги

1. В окне Claude Code в VS Code набери `/plugin` и выбери **Manage plugins**.
2. Открой вкладку с каталогом плагинов (**Marketplace**).
3. Найди в поиске **superpowers** и нажми **Install**.
4. Если спросят, куда ставить, выбирай установку **для себя** (user): так плагин будет
   работать во всех твоих проектах.
5. **Закрой VS Code целиком и открой заново.** Не только окно, а всё приложение: на
   macOS Cmd+Q, на Windows закрыть все окна. После установки это обязательно.

> Каталог висит на «Loading plugins» и ничего не загружается? Почти всегда это VPN или
> плагин после обновления Claude Code. Сначала полностью перезапусти VS Code. Не помогло,
> переподключи VPN **на ту же страну**, что обычно. Частая смена стран подряд выглядит
> для Anthropic подозрительно, так делать не надо.

## Проверка

Открой **новую** сессию и скажи:

```text
Давай проведём брейншторм: хочу придумать, как отметить день рождения друга.
```

Агент сообщает, что использует skill **superpowers:brainstorming**, и задаёт тебе первый
вопрос? Плагин работает. Дальше можно не отвечать: закрой эту сессию, настоящий брейншторм
будет по твоей идее.

Агент просто начал предлагать варианты праздника без всякого skill? Плагин не подхватился:
проверь в `/plugin` → Manage plugins, что superpowers стоит, и ещё раз перезапусти VS Code.

## Обновлять потом

Тот же `/plugin` → Manage plugins. Если у плагина горит стрелка обновления, нажми её. Агента
просить обновить плагин не нужно, это дольше и ненадёжнее.
