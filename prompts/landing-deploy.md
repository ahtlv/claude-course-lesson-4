# Лендинг в интернет: GitHub Pages

**Когда:** на занятии 4, сразу как страница собрана. Тот же путь, что со страницей Persona на
занятии 2.
**Что делает:** агент заводит публичный репозиторий, отправляет туда лендинг, включает GitHub
Pages и показывает живую ссылку.
**Как использовать:** в VS Code открыта папка `work`, отправь промпт и отвечай на вопросы.

> ⚠️ Репозиторий будет **публичным**, иначе бесплатный GitHub Pages не работает. Вместе со
> страницей уедет и документ дизайна. Это нормально: там описание идеи, а не личные данные.
> Агент спросит подтверждение перед публикацией.

```text
Выложи мой лендинг в интернет через GitHub Pages. Работаем только с папкой
work/StartUp/landing. Выполни по порядку:

1. Проверь, что я авторизован в GitHub (gh auth status). Если нет, остановись
   и скажи мне.

2. Проверь, что index.html лежит прямо в StartUp/landing, а не во вложенной папке.
   Если не так, скажи и предложи исправить.

3. Предложи короткое имя репозитория по названию моей идеи, латиницей. Предупреди,
   что он будет публичным. Дождись моего подтверждения.

4. Сделай коммит со всеми файлами, создай публичный репозиторий на GitHub и
   отправь всё в ветку main.

5. Включи GitHub Pages: публикация из ветки main, папка / (root).

6. Проверь, что первая сборка Pages запустилась. Если сборок нет совсем, сделай
   пустой коммит и отправь ещё раз.

7. Дождись, пока страница начнёт открываться, и покажи мне живую ссылку крупно.

Если на каком-то шаге ошибка, не иди дальше: объясни простыми словами, что
случилось, и предложи, что сделать.
```

Должно получиться примерно так:

```
✓ Репозиторий: github.com/твой-ник/имя-идеи
✓ GitHub Pages включён
https://твой-ник.github.io/имя-идеи/
```

Открыл ссылку, а там 404? Подожди минуту и обнови с очисткой кэша: Ctrl+F5 на Windows,
Cmd+Shift+R на macOS. Не помогло, раздел «Если что-то пошло не так» в
[deploy-guide.md](https://github.com/ahtlv/claude-course-lesson-2/blob/main/deploy-guide.md)
занятия 2.

**Кинь ссылку в чат курса.** Теперь у тебя в интернете две страницы: Persona и лендинг идеи.

**Правки потом:** попросил агента поправить страницу, сказал «закоммить и запушь», через
минуту изменения на живой ссылке. Коммит без пуша на сайт не попадает.
