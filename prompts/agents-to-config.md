# Два готовых субагента себе в `claude-config`

**Когда:** на занятии 4, после разговора про субагентов.
**Что делает:** агент скачивает из раздатки двух готовых помощников и кладёт их в папку
`agents/` внутри твоей `claude-config`. С этой минуты оба работают в любом твоём проекте.
**Как использовать:** в VS Code открыта папка `work`, отправь промпт как есть.

| Субагент | Что умеет |
|---|---|
| `anthropic-docs` | Отвечает на вопросы про сам Claude Code строго по официальной документации. Не знает ответа, так и говорит |
| `reviewer` | Ревьюер без контекста проекта: смотрит на код, текст, план или страницу свежим взглядом и говорит, что не так |

```text
Положи мне двух готовых субагентов из раздатки курса.

1. Найди мою папку claude-config: она лежит в рабочей папке work, а в системной
   папке конфига Claude Code (~/.claude на macOS и Linux, %USERPROFILE%\.claude на
   Windows) на её папку agents должна вести ссылка. Проверь это и скажи, что нашёл.
   Если ссылки нет или claude-config не нашлась, остановись и объясни.

2. Скачай два файла из репозитория github.com/ahtlv/claude-course-lesson-4,
   папка agents: anthropic-docs.md и reviewer.md. Положи их в claude-config/agents.
   Если файл с таким именем там уже есть, не перезаписывай, а спроси меня.

3. Покажи, что лежит в claude-config/agents, и одной фразой про каждого
   субагента скажи, когда он мне пригодится.

Если у меня Windows и открылся PowerShell, работай через cmd.
```

**Проверь себя.** Открой **новую** сессию (субагенты подхватываются при старте) и спроси:

```text
Спроси у субагента anthropic-docs: как в Claude Code посмотреть, сколько контекста
уже занято?
```

В ответе есть ссылка на страницу `code.claude.com/docs`, значит субагент работает.

`reviewer` пригодится сегодня же: когда лендинг будет готов, попроси «отдай страницу
субагенту reviewer, пусть посмотрит свежим взглядом».
