# Первый skill: агент пишет коммиты по твоим правилам

**Когда:** на занятии 4, после разговора о том, как устроен skill.
**Что делает:** агент собирает skill `commit-message-writer` в твоей `claude-config` и
проверяет его на настоящих изменениях. В skill зашито правило, которое модель сама не
придумает: эмодзи перед типом коммита. Увидел эмодзи, значит сработал именно твой skill, а не
общая сообразительность модели.
**Как использовать:** в VS Code открыта папка `work`, отправь промпт как есть.

> Skill это папка с файлом `SKILL.md`. Наверху короткое описание: **когда** его применять.
> Ниже инструкция: **как** делать. Агент читает только описания всех скиллов и сам решает,
> какой подходит к твоей фразе. Поэтому вызывать skill по имени не нужно: говоришь обычными
> словами, и он срабатывает.

```text
Собери мне первый skill.

1. Найди мою папку claude-config в рабочей папке work и в ней папку skills.
   Проверь, что из системной папки конфига Claude Code (~/.claude на macOS и Linux,
   %USERPROFILE%\.claude на Windows) на неё ведёт ссылка. Если нет, остановись
   и скажи.

2. Создай в skills папку commit-message-writer, а в ней файл SKILL.md.

3. В самом верху SKILL.md шапка между строками из трёх дефисов, с полями name и
   description. name: commit-message-writer. description напиши так, чтобы было
   понятно: использовать этот skill, когда я прошу написать commit-сообщение,
   оформить коммит, закоммитить изменения.

4. Ниже шапки инструкция:
   - перед тем как писать сообщение, посмотреть реальные изменения через git diff;
   - формат: тип, двоеточие, короткое описание на русском;
   - типы: feat (новое), fix (исправление), docs (тексты), refactor (переделка
     без нового поведения), chore (служебное);
   - обязательное правило: перед типом всегда ставить эмодзи по смыслу:
     ✨ для feat, 🐛 для fix, 📝 для docs, ♻️ для refactor, 🔧 для chore.

5. Покажи мне готовый файл целиком и объясни в двух предложениях, какая строка
   отвечает за «когда», а какая за «как».

Если у меня Windows и открылся PowerShell, работай через cmd.
```

## Проверка

1. Перезапусти VS Code: новый skill надёжно подхватывается на чистом старте.
2. Открой папку `Persona` (там есть git) и попроси агента поменять на странице любую мелочь,
   например одно слово в подвале.
3. Теперь **не называй skill по имени**, просто скажи обычной фразой:

```text
Напиши commit-сообщение для моих изменений.
```

В ответе эмодзи перед типом, например `✨ feat: ...` или `📝 docs: ...`? Сработал твой skill.

**Эмодзи нет.** Так бывает, если описание расплывчатое. Скажи агенту: «перепиши description
в commit-message-writer конкретнее, чтобы он срабатывал на фразу "напиши commit-сообщение"»,
перезапусти VS Code и попробуй ещё раз. Это не сбой, а ровно то, как настраиваются скиллы.
